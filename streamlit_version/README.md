# Cocktail Planner Vicennole - Streamlit Version

Versione web dell'applicazione basata su Python e Streamlit.

## Requisiti

```bash
pip install streamlit reportlab
```

## Avvio

```bash
streamlit run app.py
```

## Funzionalità

- ✅ 30 cocktail in 4 categorie
- ✅ Calcolo automatico ingredienti
- ✅ Distribuzione personalizzabile
- ✅ Checklist spesa interattiva
- ✅ Sistema note
- ✅ Salvataggio sessioni (JSON locale)
- ✅ Export PDF

Questa è la versione originale Python/Streamlit dell'app.
